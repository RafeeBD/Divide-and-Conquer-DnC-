# Divide and Conquer (DnC) Algorithms

This repository contains C++ implementations of various Divide and Conquer algorithms and problem solutions.

## 📁 Repository Structure

All problem solutions and algorithm implementations are located inside the [`Problems/`](./Problems) folder:

- **[DnC - Sum Divisible by 7.cpp](./Problems/DnC%20-%20Sum%20Divisible%20by%207.cpp)**: Find subarray/elements with sum divisible by 7 using Divide and Conquer.
- **[Max element.cpp](./Problems/Max%20element.cpp)**: Find maximum element in an array using Divide and Conquer.
- **[Min element.cpp](./Problems/Min%20element.cpp)**: Find minimum element in an array using Divide and Conquer.
- **[Maxsumsub.cpp](./Problems/Maxsumsub.cpp)**: Maximum Subarray Sum (Kadane's / Divide and Conquer approach).
- **[Mergesort.cpp](./Problems/Mergesort.cpp)**: Merge Sort implementation.
- **[Quicksort.cpp](./Problems/Quicksort.cpp)**: Quick Sort implementation.
- **[divide and conquer.cpp](./Problems/divide%20and%20conquer.cpp)**: Basic Divide and Conquer demonstration.

## 🚀 How to Run

Compile any `.cpp` file using a C++ compiler (such as `g++`):

```bash
g++ -o solution "Problems/Mergesort.cpp"
./solution
```
