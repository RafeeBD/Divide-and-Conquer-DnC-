# Divide and Conquer (DnC) Algorithms

This repository contains C++ implementations of various Divide and Conquer algorithms.

## 📁 Repository Structure

### 🔹 Core Algorithms (Root)
- **[Max element.cpp](./Max%20element.cpp)**: Find maximum element in an array using Divide and Conquer.
- **[Min element.cpp](./Min%20element.cpp)**: Find minimum element in an array using Divide and Conquer.
- **[Maxsumsub.cpp](./Maxsumsub.cpp)**: Maximum Subarray Sum (Kadane's / Divide and Conquer approach).
- **[Mergesort.cpp](./Mergesort.cpp)**: Merge Sort implementation.
- **[Quicksort.cpp](./Quicksort.cpp)**: Quick Sort implementation.
- **[divide and conquer.cpp](./divide%20and%20conquer.cpp)**: Basic Divide and Conquer demonstration.

### 📁 Problems Folder
- **[Problems/DnC - Sum Divisible by 7.cpp](./Problems/DnC%20-%20Sum%20Divisible%20by%207.cpp)**: Find count/sum of subarrays divisible by 7 using Divide and Conquer.

## 🚀 How to Run

Compile any `.cpp` file using a C++ compiler (such as `g++`):

```bash
g++ -o solution "Problems/DnC - Sum Divisible by 7.cpp"
./solution
```
